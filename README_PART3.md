# Three.js React Project - Part 3

## Выполненные задания

### 1. Разделение на компоненты

Код разделен на следующие компоненты:

#### **components/ControlPanel.tsx**
Главная панель управления, объединяющая все подкомпоненты.

#### **components/ModelLoader.tsx**
Компонент для загрузки 3D моделей:
- Поддержка GLTF, GLB, OBJ, FBX форматов
- Input для выбора файлов

#### **components/LightingControls.tsx**
Управление освещением сцены:
- Интенсивность света
- Цвет света
- Цвет пирамиды

#### **components/ObjectTransform.tsx**
Управление трансформацией выбранного объекта:
- Режимы: перемещение, поворот, масштаб
- Числовые поля для точного ввода позиции, поворота (в градусах), масштаба

### 2. GLSL шейдер (Пользовательский)

#### **shaders/waveShader.ts**
Создан кастомный GLSL шейдер с следующими эффектами:

**Vertex Shader:**
- Волновой эффект, деформирующий геометрию
- Использует функции `sin` и `cos` для создания анимированных волн
- Параметры: `time`, `amplitude`

**Fragment Shader:**
- Анимированный градиент между двумя цветами
- Освещение на основе нормалей
- Fresnel эффект (свечение на краях объекта)
- Параметры: `time`, `color1`, `color2`

#### Применение шейдера
Шейдер применен к плоскости "Волновая плоскость (GLSL)":
- Видна по умолчанию в сцене
- Расположена в центре, немного позади других объектов
- Анимируется в реальном времени
- Имеет волнистую деформацию и красивый градиентный эффект

## Структура проекта

```
src/
├── components/
│   ├── ControlPanel.tsx       # Главная панель управления
│   ├── ModelLoader.tsx         # Загрузка моделей
│   ├── ObjectTransform.tsx     # Трансформация объектов
│   └── LightingControls.tsx    # Управление светом
├── shaders/
│   └── waveShader.ts          # GLSL шейдер с волновым эффектом
├── App.tsx                     # Главный компонент с 3D сценой
├── App.css                     # Стили
└── main.tsx                    # Точка входа
```

## Особенности реализации

1. **Модульность**: Каждый компонент имеет четкую область ответственности
2. **Типобезопасность**: Все компоненты типизированы с использованием TypeScript
3. **Производительность**: Шейдер работает на GPU, обеспечивая плавную анимацию
4. **Визуальные эффекты**: Комбинация волнового эффекта, градиента и Fresnel создает впечатляющий визуал
